# Companies

Put real company notes in this folder, created from `templates/Company Template.md`.

Only real companies belong here. Keep shared organization context here; keep personal details and communication history in the linked contact notes under `contacts/`.

Recommended filename format:

```text
Company Name.md
```

Examples:

```text
Acme Inc.md
SMMAR.md
```

Do not put real company data in `samples/`. That folder is only for example data.
