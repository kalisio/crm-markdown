# Contacts

Put real contact notes in this folder.

Only real contacts belong here. Samples are intentionally kept outside this folder so they do not appear in the contact dashboards.

When a contact belongs to a company (see `companies/`), put their note in a subfolder named after that company. Contacts with no company, or whose company doesn't need its own subfolder, go directly in `contacts/`.

Recommended filename format:

```text
First Last.md
```

Examples:

```text
Jane Doe.md
Sam Patel.md
Evelyn Park.md
```

Do not put real contacts in `samples/`. That folder is only for example data.
